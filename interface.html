5. Пользовательский интерфейс

Для повседневных действий я создала три страницы в общем оформлении с помощью Bootstrap. JavaScript загружает данные через REST API и отправляет формы без перезагрузки страницы. Результат операции или ошибка отображаются сообщением.

Номера

На странице / выводится таблица номеров с этажом, типом, вместимостью, ценой за ночь и телефоном. Ниже расположена форма добавления номера. Этажи и типы загружаются из API; перед созданием номера эти справочники должны быть заполнены.

Рисунок 1 — Страница гостиничных номеров.

Гости

На странице /guests/ я разместила список постояльцев и форму регистрации. В форме указываются ФИО, серия и номер паспорта, а также город прибытия. После сохранения список гостей обновляется.

Рисунок 2 — Страница постояльцев.

Заселение

На странице /check-in/ выбираются номер, гости, дата заезда и плановая дата выезда. Для выбора нескольких гостей я добавила выпадающий список с чекбоксами и поиском по ФИО. Выбор выполняется обычными кликами, а закрытое поле показывает количество выбранных гостей. При отправке формы API получает массив их ID.

После успешного заселения форма очищается. Вместимость номера, корректность дат и занятость проверяются на сервере. Выселение, работа с сотрудниками, аналитика и квартальный отчёт реализованы через API.
