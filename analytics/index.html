Пять аналитических запросов

Все запросы — GET для is_staff=True; вход с сессией или токеном. Параметры проверяются Serializer, ошибки дают 400; неизвестный гость/номер — 404. Результаты вычисляются через ORM и не сохраняются. Границы периодов полуоткрытые.

URL после /api/analytics/ Параметры Результат
room-guests/ room_id, date_from, date_to Уникальные гости номера за период
guests-by-city/ city Число зарегистрированных гостей из города
guest-cleaner/ guest_id, date Назначенные уборщики этажа номера гостя
available-rooms/ date_from, date_to Свободные на всём периоде номера
concurrent-guests/ guest_id Гости, проживавшие одновременно с выбранным

Гости номера

GET /api/analytics/room-guests/?room_id=1&date_from=2026-11-01&date_to=2026-12-01

{"room_id": 1, "date_from": "2026-11-01", "date_to": "2026-12-01", "guests": [{"id": 1, "first_name": "Иван", "last_name": "Тестовый", "middle_name": ""}], "count": 1}

Гость с несколькими заездами учитывается один раз через distinct(). Паспорт в аналитической сводке не возвращается.

Город

GET /api/analytics/guests-by-city/?city=Москва

{"city": "Москва", "count": 3}

Это число записей Guest, включая гостей без заселений, а не число текущих жильцов и не число заездов. Регистр не учитывается, пробелы по краям параметра удаляются.

Уборщик

GET /api/analytics/guest-cleaner/?guest_id=1&date=2026-11-03

{"guest_id": 1, "date": "2026-11-03", "room_id": 1, "floor_id": 1, "employees": [{"id": 1, "first_name": "Анна", "last_name": "Тестовая", "middle_name": ""}]}

Учитываются этаж проживания, день недели, период назначения, приём и увольнение. День окончания назначения/увольнения исключается. Если проживания нет, room_id и floor_id равны null, employees пуст, добавляется message. Если нет уборщиков, employees пуст, но номер и этаж заполнены. Фактическое выполнение уборки не регистрируется.

Свободные номера

GET /api/analytics/available-rooms/?date_from=2026-11-01&date_to=2026-11-05

{"date_from": "2026-11-01", "date_to": "2026-11-05", "rooms": [{"id": 2, "number": "102"}], "count": 1}

Исключаются все номера с хотя бы одним пересечением. Наличие свободного места в занятом номере не делает номер свободным.

Одновременно проживавшие

GET /api/analytics/concurrent-guests/?guest_id=1

{"guest_id": 1, "guests": [{"id": 2, "first_name": "Олег", "last_name": "Тестовый", "middle_name": ""}], "count": 1}

Проверяются все заезды выбранного гостя и пересечения по всей гостинице, включая другие номера. Сам гость исключён, повторы удалены. Соприкосновение выезда и заезда без общей ночи не считается пересечением. Во всех запросах фактическая дата выезда имеет приоритет над плановой.
