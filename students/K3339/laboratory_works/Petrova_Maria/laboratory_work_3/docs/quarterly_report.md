# Квартальный отчёт

```http
GET /api/reports/quarterly/?year=2026&quarter=4
Authorization: Token <токен_администратора>
```

Только активный `is_staff=True`, также работает сессия Django.
APIView проверяет параметры через QuarterlyReportQuerySerializer и вызывает
простую функцию quarterly_report из services.py. Дополнительных таблиц нет.

year — целое от 1 до 9998: следующий год нужен для вычисления конца IV квартала.
quarter — целое от 1 до 4. Оба параметра обязательны; неверные значения дают 400.
Кварталы: `[01.01, 01.04)`, `[01.04, 01.07)`, `[01.07, 01.10)`,
`[01.10, 01.01 следующего года)`.

## Расчёт

1. ORM выбирает Accommodation, пересекающие квартал, и заранее загружает Stay.
2. Конец проживания — actual_check_out, если заполнен, иначе planned_check_out.
3. Начало пересечения — max(check_in, начало квартала), конец — min(выезд, конец квартала).
4. Количество ночей — разница дат пересечения. День выезда не оплачивается.
5. Доход — ночи × Accommodation.price_per_night. Используются Decimal и снимок тарифа.
6. Для каждого номера собирается множество guest_id: повторный гость считается один раз.
7. Все Room включаются в результат, даже пустые. Все Floor включаются через
   annotate(room_count=Count("rooms")), включая этажи без номеров.

Цена начисляется один раз за Accommodation, независимо от числа Stay. Общий доход —
сумма доходов номеров. Изменение текущего тарифа RoomType не меняет старое заселение.
Доход включает все пересекающие квартал ночи по указанным датам, включая плановые;
по сегодняшней дате отчёт не обрезается. Это расчётная стоимость, а не журнал платежей.

## Пример

Два гостя живут в номере 101 по тарифу 5000 с 30 сентября до 3 октября 2026.
В IV квартал входят две ночи: 1 и 2 октября. Доход — 10000, гостей — 2.
Если один гость приедет ещё раз, guest_count останется 2, а доход увеличится.

Для гостиницы из двух номеров на первом этаже и пустого второго этажа:

```json
{
  "year": 2026,
  "quarter": 4,
  "rooms": [
    {"room_id": 1, "room_number": "101", "guest_count": 2, "revenue": "10000.00"},
    {"room_id": 2, "room_number": "102", "guest_count": 0, "revenue": "0.00"}
  ],
  "floors": [
    {"floor_id": 1, "floor_number": 1, "room_count": 2},
    {"floor_id": 2, "floor_number": 2, "room_count": 0}
  ],
  "total_revenue": "10000.00"
}
```

Денежные значения возвращаются строками с двумя десятичными знаками.
Если гостиница пуста, оба списка пусты и total_revenue равен "0.00".
